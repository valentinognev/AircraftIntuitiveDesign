# flow5 v1 (Analyze solver) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Vendor flow5’s solver libraries into this repo, convert AID aircraft JSONC into a flow5 plane, run native flow5, expose that as Analyze → flow5, and prove Cessna 172 AID results match the native run at parser precision.

**Architecture:** Python never reimplements the panel solver. `aid.flow5_io.write_flow5_deck` maps `Aircraft` → JSON deck. Vendored `FLOW5/run/flow5_run` (C++ linked to vendored `flow5-lib` + `XFoil-lib`) is the only native calculation. `run_flow5(ac, mesh)` writes that deck and subprocesses the helper. E2E success is byte-for-byte numeric equality (atol 1e-6) between (1) helper on the written deck and (2) `run_flow5`. GUI only stores `last_results["flow5"]` from that wrapper. No fuselage, inviscid, thin surfaces, Type-1 polar, VLM2. No MATLAB.

**Tech Stack:** Linux, g++ C++20, CMake ≥ 3.16, OpenCASCADE (OCCT) headers/libs, OpenBLAS, Python 3.11+, pytest, PySide6, numpy, existing `aid` package. flow5 GPL-3 (subprocess helper, same pattern as AVL).

**Spec:** This plan is the binding spec for flow5 v1 (chat design 2026-08-29). Parent AID spec: `Docs/2026-08-26-aid-linux-python-port-spec.md`.

## Deck JSON schema (lock)

Written by Python, read by `flow5_run`. SI + degrees.

```json
{
  "name": "Cessna 172",
  "foils": [{"name": "NACA 2412", "naca": 2412}],
  "wings": [
    {
      "role": "main",
      "name": "Wing",
      "position_m": [0.67056, 0.0, 0.35049],
      "rx_deg": 0.0,
      "ry_deg": 0.0,
      "nx": 10,
      "closed_inner": false,
      "sections": [
        {
          "y_m": 0.0,
          "chord_m": 0.609603,
          "x_offset_m": 0.0,
          "dihedral_deg": 3.0,
          "twist_deg": 0.0,
          "ny": 10,
          "foil": "NACA 2412"
        }
      ]
    }
  ],
  "polar": {
    "type": "T1",
    "method": "VLM2",
    "thin": true,
    "viscous": false,
    "qinf_mps": 10.0,
    "density": 1.225,
    "viscosity": 1.5e-5,
    "sref_m2": 2.230,
    "cref_m": 0.609603,
    "bref_m": 3.6576,
    "cog_m": [0.8961, 0.0, 0.0],
    "mass_kg": 2.268,
    "alpha_deg": [-4.0, 0.0, 4.0, 8.0, 12.0]
  }
}
```

`role` is one of `main`, `elevator`, `fin`, `other`. Fin: `rx_deg=-90`, `closed_inner=true`. Wing `position_m` is LE root in AID body axes converted to metres (`WG.X,Y,Z` / `HT.*` / `VT.*`). `x_offset_m` is section LE x minus root LE x (from `geometry()` `X`/`Xtip`/`Xbrk`). `twist_deg` is section incidence in the AID sense (`i` at root, `i-TWISTA` at tip for linear washout).

Helper **stdout** (only JSON, no log on stdout; logs on stderr):

```json
{"alpha": [-4.0, 0.0, 4.0, 8.0, 12.0], "CL": [], "CD": [], "Cm": [], "CLa": 0.0, "Cma": 0.0}
```

`CLa`/`Cma` are d(coeff)/d(α_rad) from a linear fit of the table (least squares). Tables are the gold; slopes are convenience for plots.
